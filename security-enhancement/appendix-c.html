Appendix C: Compliance Mapping Matrix

This appendix maps all 50 vulnerabilities from the Claude Code security audit to six major compliance frameworks: OWASP Top 10 (2021), CWE (Common Weakness Enumeration), SOC 2 Type II, HIPAA Security Rule, FedRAMP (based on NIST SP 800-53), and NIST Cybersecurity Framework (CSF). The purpose is to enable compliance teams to assess remediation priority through the lens of their specific regulatory requirements.

Framework Overview

Framework Scope Applicability to Claude Code
OWASP Top 10 (2021) Web application security risks Direct: Claude Code has web-facing components (bridge, OAuth, API)
CWE Software weakness classification Direct: Every finding maps to a CWE
SOC 2 Type II Trust service criteria Indirect: Organizations using Claude Code may require SOC 2
HIPAA Security Rule Protected health information Indirect: Healthcare orgs using Claude Code for PHI-adjacent work
FedRAMP / NIST 800-53 Federal information systems Indirect: Government contractors using Claude Code

Recommendations for Compliance Teams

  1. For SOC 2 audits: Prioritize Phases 1-3. Plugin signing (V-1, V-2) and credential encryption (V-7-V-10) are the most significant gaps. Document compensating controls for findings not yet remediated.

  2. For HIPAA compliance: Do not use Claude Code with PHI-adjacent workloads until Phases 1-3 are complete. The plaintext credential and history storage (V-7, V-8, V-9) are direct HIPAA violations. Implement conversation history encryption before any healthcare deployment.

  3. For FedRAMP authorization: The 2 CRITICAL findings (V-1, V-2) will block any FedRAMP authorization. Address all LOW baseline controls (16 findings) for a LOW authorization. MODERATE authorization requires 21 findings addressed. HIGH authorization requires 22.

  4. For NIST CSF alignment: Focus on PROTECT function gaps first. The PR.DS (Data Security) category has the most findings and the broadest impact. The DETECT function gaps are secondary but important for operational monitoring.

  5. For all frameworks: The debug log redaction patches (Chapter 18) provide immediate compliance improvement across all frameworks at minimal cost (estimated 5-6 hours). Apply these first as quick wins while planning larger remediation efforts.

Using This Matrix

For Security Engineers

Start with the Cross-Framework Priority Matrix in the main body. The findings with 5-framework coverage (V-1, V-2, V-5, V-7, V-8, V-9, V-3) are your highest-priority targets. Addressing these 7 findings resolves compliance gaps across all frameworks simultaneously.

For Compliance Officers

Use the Framework-Specific Sections (OWASP, SOC 2, HIPAA, FedRAMP, NIST CSF) to map audit findings to your specific framework requirements. The Compensating Controls Matrix provides acceptable temporary mitigations for findings that cannot be immediately remediated.

For Auditors

The Audit Evidence Collection Guide maps each control to specific implementation artifacts. Request these artifacts during evidence collection. The patch code, test results, and monitoring configurations constitute the implementation evidence for each control.
