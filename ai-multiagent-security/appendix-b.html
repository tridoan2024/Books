Appendix B: CWE Reference for AI Agent Vulnerabilities

This appendix maps Common Weakness Enumeration (CWE) entries to AI agent-specific exploitation contexts. Each CWE includes its standard definition, how it manifests in AI agent systems, concrete exploitation scenarios, and references to the chapters where the vulnerability is analyzed in depth.

CWEs are organized by relevance to AI agent security, from most critical to informational.

Critical: AI Agent-Specific Exploitation

CWE-94: Improper Control of Generation of Code

Standard definition: The product constructs all or part of a code segment using externally-influenced input, but does not neutralize or incorrectly neutralizes special elements that could modify the intended code.

AI agent context: In AI agents, "code generation" extends beyond traditional code injection. The LLM generates tool calls, shell commands, file edits, and API requests based on context that includes untrusted content. Prompt injection manipulates the LLM into generating unintended code.

Exploitation in AI agents: - MCP tool descriptions loaded into the system prompt instruct the LLM to generate specific tool calls (Chapter 19) - Project hook configuration in .claude/settings.json injects arbitrary commands at session start (Chapter 22) - SessionStart hooks inject arbitrary text into the system prompt via additionalContext (Chapter 22) - Poisoned file content read by the agent influences subsequent code generation

Detection: Scan MCP tool descriptions for imperative instructions. Monitor generated tool calls for deviation from conversation context. Audit hook configurations for command execution.

CWE-78: Improper Neutralization of Special Elements used in an OS Command

Standard definition: The product constructs an OS command using externally-influenced input without properly neutralizing special elements.

AI agent context: AI agents generate shell commands based on user prompts and LLM reasoning. The command is a string that may include shell metacharacters, variable expansion, command substitution, and quoting patterns that alter its meaning.

Exploitation in AI agents: - The LLM generates a command containing injected shell metacharacters from prompt injection (Chapter 5) - Regex-based command validation fails to detect encoded commands (base64, eval, indirect execution) (Chapter 22) - Parser differentials between the validation layer and the shell execution layer allow bypass (Chapter 5)

Detection: Compare validated command string against actual executed command. Use AST-based command parsing rather than regex matching. Monitor for indirect execution patterns (eval, bash -c, process substitution).

CWE-494: Download of Code Without Integrity Check

Standard definition: The product downloads source code or an executable from a remote location and executes it without sufficiently verifying the origin or integrity.

AI agent context: MCP servers installed via npx -y are downloaded from npm registries and executed without signature verification. Plugin/extension systems download code from marketplaces without cryptographic integrity validation.

Exploitation in AI agents: - Malicious MCP server package published to npm, installed via npx -y @latest (Chapter 21) - Typosquatted package names redirect to attacker-controlled servers (Chapter 21) - Compromised CDN or MITM on marketplace download delivers modified plugins (audit finding CVSS 9.1) - Server update attacks: legitimate package updated with malicious payload post-installation (Chapter 21)

Detection: Verify package checksums against known-good values. Enforce version pinning. Implement SLSA provenance verification. Monitor for unexpected package version changes.

CWE-269: Improper Privilege Management

Standard definition: The product does not properly assign, modify, track, or check privileges for an actor.

AI agent context: MCP servers receive broad privileges (tool provision, result injection, notification sending) based on a single user approval. Subagents share the parent agent's process and may inherit broader privileges than intended.

Exploitation in AI agents: - MCP server approved once receives permanent trust for all current and future tools (Chapter 19) - Subagents execute in the parent process with access to shared state (audit finding CVSS 7.8) - Tool-creating agents escalate from restricted tools to unrestricted execution (Chapter 24) - Permission escalation through configuration: project settings add Bash(*) allow rule (Chapter 22)

Detection: Audit per-server privilege scope. Verify subagent tool restrictions are process-level, not name-based. Monitor for privilege boundary violations in tool call logs.

CWE-345: Insufficient Verification of Data Authenticity

Standard definition: The product does not sufficiently verify the origin or authenticity of data, which may lead to accepting invalid data.

AI agent context: MCP server outputs (tool results, capability declarations, annotations) are accepted without provenance verification. The agent treats MCP-sourced data with the same authority as built-in tool output.

Exploitation in AI agents: - Capability negotiation accepts self-reported declarations without attestation (Chapter 19) - Tool annotations (readOnlyHint, destructiveHint) are self-reported and unverifiable (Chapter 20) - Tool results flow into LLM context without provenance tagging (Chapter 19) - Server identity is not verified -- any process at the pipe endpoint is "authenticated" (Chapter 19)

CWE-862: Missing Authorization

Standard definition: The product does not perform an authorization check when an actor attempts to access a resource or perform an action.

AI agent context: MCP server installation lacks authorization beyond a one-time user approval. The AI permission classifier uses server-provided metadata (circular trust). The dangerouslySkipPermissions flag bypasses all checks.

Exploitation in AI agents: - No re-authorization when MCP server updates its code (Chapter 21) - Auto-mode classifier approves tools based on manipulated descriptions (Chapter 20) - dangerouslySkipPermissions flag sent to remote servers (audit finding CVSS 6.5) - Accept-edits mode auto-allows filesystem commands without prompt (audit finding CVSS 4.0)

High: Common in AI Agent Architectures

CWE-22: Improper Limitation of a Pathname to a Restricted Directory (Path Traversal)

AI agent context: Agents read and write files based on LLM-generated paths. Path traversal allows the agent to access files outside the intended project directory.

Exploitation: Symlink-based traversal in ZIP extraction (audit finding CVSS 7.5). The LLM generates ../../../etc/shadow as a file path through prompt injection. ZIP slip attacks through MCP server plugin packages.

CWE-312: Cleartext Storage of Sensitive Information

AI agent context: Credentials, session transcripts, and conversation history are stored as plaintext files on disk.

Exploitation: OAuth tokens stored in ~/.claude/.credentials.json with only chmod 600 protection (audit finding CVSS 7.1). Conversation history containing source code stored unencrypted (audit finding CVSS 7.0). Any same-user process can read credentials on Linux where no keychain is implemented.

CWE-347: Improper Verification of Cryptographic Signature

AI agent context: JWT tokens are decoded without signature verification, relying on the TLS transport for integrity.

Exploitation: JWT decoded via base64url parsing without calling verify() (audit finding CVSS 7.5). Attacker with MITM capability forges JWT with modified expiry claim, preventing token refresh or forcing constant refresh loops (DoS).

CWE-250: Execution with Unnecessary Privileges

AI agent context: MCP servers and hooks execute with full user-level OS privileges, not restricted to the minimum needed for their function.

Exploitation: MCP tools execute without process sandbox (audit finding CVSS 7.5). Hook scripts have full filesystem, network, and process access. A malicious MCP server can read arbitrary files, make network connections, and spawn processes.

CWE-829: Inclusion of Functionality from Untrusted Control Sphere

AI agent context: MCP servers defined in repository configuration execute arbitrary code. Project hooks execute arbitrary commands. Plugin systems load and execute external code.

Exploitation: .mcp.json in a cloned repository defines a malicious server (Chapter 21). Project settings.json defines hooks that exfiltrate data (Chapter 22). Remote configuration controls analytics pipeline behavior (audit finding CVSS 3.5).

CWE-674: Uncontrolled Recursion

AI agent context: Subagents can fork additional subagents. Without depth limits, recursive forking consumes unbounded resources.

Exploitation: Recursive subagent forking with weak depth guard (audit finding CVSS 6.2). Fork children retain the Agent tool, enabling further recursion. Prompt injection instructs the agent to spawn subagents that spawn more subagents.

Medium: Frequently Encountered

CWE-400: Uncontrolled Resource Consumption

AI agent context: MCP notification flooding, context window exhaustion through large tool results, timeout gaming.

Exploitation: MCP server sends thousands of notifications per second (Chapter 19). Tool results near the size limit accumulate across calls (Chapter 20). Just-under-timeout responses maximize wall-clock waste.

CWE-367: Time-of-Check Time-of-Use (TOCTOU)

AI agent context: File state changes between permission validation and tool execution. Credential file state changes between read check and write.

Exploitation: TOCTOU between read state check and file write (audit finding CVSS 5.0). Symlink created between hook evaluation and command execution (Chapter 22). Credential migration race condition (audit finding CVSS 3.3).

CWE-532: Insertion of Sensitive Information into Log File

AI agent context: Debug logs, telemetry, and error messages may contain token prefixes, session IDs, file paths, or tool arguments.

Exploitation: Token prefix logged in debug output (audit findings CVSS 4.3, 3.1). Tool input arguments logged to telemetry (audit finding CVSS 2.4). Debug logs contain sensitive URLs and session identifiers (audit finding CVSS 2.7).

CWE-426: Untrusted Search Path

AI agent context: Hook scripts specified with relative paths. MCP server commands resolved through PATH. Environment variables from project settings modify execution paths.

Exploitation: Project settings inject LD_PRELOAD, NODE_OPTIONS, PYTHONSTARTUP (Chapter 22). Hook commands resolved via relative paths can be replaced (Chapter 22). PATH manipulation redirects MCP server invocation.

CWE-522: Insufficiently Protected Credentials

AI agent context: Proxy authentication credentials in WebSocket headers. Base64-encoded credentials in memory. OAuth tokens accessible to child processes.

Exploitation: Proxy credentials encoded as Base64 Basic Auth in memory (audit finding CVSS 4.4). Proxy authentication credentials in WebSocket headers (audit finding CVSS 5.4). Credentials inherited by spawned MCP servers.

CWE-913: Improper Control of Dynamically-Managed Code Resources

AI agent context: MCP tool lists change at runtime via listChanged notifications. Capability inflation adds unexpected functionality.

Exploitation: Server periodically changes tool list, each change an opportunity for description injection (Chapter 19). Progressive escalation adds malicious tools after trust-building period (Chapter 21).

CWE-1321: Improperly Controlled Modification of Object Prototype Attributes

AI agent context: JSON-RPC messages parsed from MCP servers may contain __proto__ keys.

Exploitation: Prototype pollution through MCP server responses if post-parse processing uses Object.assign() or spread operators (Chapter 19). May affect security-relevant checks in the permission system.

CWE-636: Not Failing Securely

AI agent context: Hook system defaults to fail-open for hook errors. Security hooks that crash or timeout allow the action to proceed.

Exploitation: Attacker crafts input that crashes a security hook (large payload causing parse timeout), effectively disabling that hook's protection (Chapter 22). An attacker who can cause network latency for HTTP hooks can make them timeout and fail-open.

CWE-757: Selection of Less-Secure Algorithm During Negotiation

AI agent context: MCP capability negotiation can be downgraded by stripping capabilities from the server response.

Exploitation: MITM strips resources capability, degrading LLM's ability to generate correct queries (Chapter 19). Downgraded capability is indistinguishable from a server that genuinely lacks the capability.

Low / Informational

CWE-200: Exposure of Sensitive Information to an Unauthorized Actor

AI agent context: Root listing reveals directory structure. File paths in error messages. Telemetry data sent to third parties without explicit consent. Tool arguments may contain sensitive data.

CWE-306: Missing Authentication for Critical Function

AI agent context: stdio MCP transport has no message authentication. Any process with pipe access can inject or observe messages.

CWE-441: Unintended Proxy or Intermediary

AI agent context: The sampling capability turns the agent into an LLM proxy for MCP servers. Servers can request completions under the user's API credentials.

CWE-451: User Interface Misrepresentation of Critical Information

AI agent context: MCP server log messages displayed as system messages. Users may interpret server-originated messages as agent system messages and follow malicious instructions.

CWE-706: Use of Incorrectly-Resolved Name or Reference

AI agent context: MCP namespace prefix depends on configuration name integrity. Namespace squatting (confusable names) can redirect tool calls.

CWE-1288: Improper Validation of Consistency within Input

AI agent context: The agent does not validate that successive MCP results are consistent with each other or with the codebase state. Enables gradual context poisoning.

Usage Notes

  1. For vulnerability reports: Reference both the CWE ID and the AI agent-specific exploitation context. Standard CWE descriptions do not capture the unique threat model of AI agents.

  2. For threat modeling: Use this appendix alongside the threat model template in Appendix C. Map identified threats to CWEs for standardized classification.

  3. For compliance mapping: CWEs map to OWASP categories (A01-A10), NIST controls, and other framework requirements. Use the compliance mapping in Chapter 23 to connect CWE findings to specific compliance gaps.

  4. For prioritization: The severity ordering in this appendix reflects AI agent-specific risk, which may differ from the CWE's general severity. CWE-94 (code injection) is universally critical, but CWE-1288 (input consistency) becomes high-severity specifically in AI agents where gradual context poisoning is a viable attack.
