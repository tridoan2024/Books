Chapter 28: Multi-Agent Orchestration Engine

"A semaphore is not a ceiling — it is a queue. The work does not disappear when you cap concurrency; it waits its turn."

Chapter 27 built the permission layer. We now have a harness that can spawn a single agent, validate its tool calls, and enforce safety policies. That is a foundation. This chapter builds the structure that sits on top of it: the orchestration engine that coordinates dozens of agents simultaneously, streams results through staged pipelines, enforces concurrency budgets, and recovers from partial failures without starting over.

The design mirrors Claude Code's own Workflow engine closely. By the end of this chapter you will have implemented in Python: a semaphore-backed agent pool, pipeline() without barriers, parallel() with barrier semantics, structured output validation with retry, a phase-and-narrator progress system, and a journal-based resume cache. The lab assembles these into a self-contained workflow engine with the same operational properties as the reference implementation.

28.1 Agent Spawn/Join Primitives: launch, wait, cancel, timeout

Before building the scheduler, establish what an agent call looks like at the primitive level. Every higher-level construct — pipeline, parallel, resume — is built on top of these four operations.

An agent in our engine is an asyncio.Task wrapping an API call. The harness sends a prompt to the Anthropic API, receives a response, and returns either a string or a validated object. The primitives are:

  • launch: wrap the call in a task and register it with the pool
  • wait: await the task's result
  • cancel: cancel the underlying asyncio.Task and mark the entry null
  • timeout: cancel automatically after a deadline
from __future__ import annotations

import asyncio
import time
from dataclasses import dataclass, field
from typing import Any, Callable, Coroutine, Optional


@dataclass
class AgentHandle:
    """Live reference to a running agent task."""
    task_id: str
    label: str
    task: asyncio.Task[Any]
    started_at: float = field(default_factory=time.monotonic)

    async def wait(self, timeout: Optional[float] = None) -> Any:
        """Await completion. Returns result or None on cancel/timeout/error."""
        try:
            if timeout is not None:
                return await asyncio.wait_for(asyncio.shield(self.task), timeout=timeout)
            return await self.task
        except asyncio.TimeoutError:
            self.task.cancel()
            return None
        except asyncio.CancelledError:
            return None
        except Exception:
            return None

    def cancel(self) -> None:
        """Cancel the agent immediately."""
        if not self.task.done():
            self.task.cancel()


class AgentPool:
    """Tracks all live agent handles for a workflow run."""

    def __init__(self) -> None:
        self._handles: dict[str, AgentHandle] = {}
        self._counter: int = 0

    def register(self, label: str, task: asyncio.Task[Any]) -> AgentHandle:
        self._counter += 1
        task_id = f"agent-{self._counter:04d}"
        handle = AgentHandle(task_id=task_id, label=label, task=task)
        self._handles[task_id] = handle
        return handle

    async def cancel_all(self) -> None:
        for handle in self._handles.values():
            handle.cancel()
        # Give cancelled tasks a chance to clean up
        pending = [h.task for h in self._handles.values() if not h.task.done()]
        if pending:
            await asyncio.gather(*pending, return_exceptions=True)

    @property
    def active_count(self) -> int:
        return sum(1 for h in self._handles.values() if not h.task.done())

    @property
    def total_launched(self) -> int:
        return self._counter

The AgentHandle separates identity from execution. When a pipeline passes a result downstream, it passes the awaited value — not the handle. The handle exists only for lifecycle management: cancellation, timeout enforcement, and pool accounting.

The wait() method swallows all errors and returns None. This is load-bearing. Upstream callers — pipeline(), parallel() — treat None as a dropped item and continue. They do not need to handle exceptions. This is the same contract as Claude Code's workflow engine: a throwing agent resolves to null, never propagates an exception to the orchestrator.

28.2 Concurrency Control: Semaphore with Configurable Cap, Queuing Excess Requests

The concurrency cap is not an arbitrary limit. It matches the Claude Code formula:

min(16, CPU_CORES - 2)

On a 12-core machine this is 10. On a 4-core machine this is 2. The formula keeps the machine responsive by leaving headroom for the shell, LSP, and progress UI. Excess agent launches do not fail — they queue behind the semaphore and execute as slots open.

import os
from typing import TypeVar

T = TypeVar("T")

_DEFAULT_CAP = min(16, max(1, os.cpu_count() - 2))  # type: ignore[operator]
_LIFETIME_CAP = 1000


class ConcurrencyGuard:
    """
    Semaphore-backed concurrency controller with lifetime cap.

    Simultaneous limit: min(16, cpu_cores - 2)
    Lifetime limit: 1000 agents per workflow run
    Excess calls: queued, not rejected
    """

    def __init__(self, simultaneous_cap: int = _DEFAULT_CAP) -> None:
        self._semaphore = asyncio.Semaphore(simultaneous_cap)
        self._simultaneous_cap = simultaneous_cap
        self._lifetime_launched: int = 0
        self._lifetime_cap: int = _LIFETIME_CAP

    @property
    def simultaneous_cap(self) -> int:
        return self._simultaneous_cap

    @property
    def lifetime_remaining(self) -> int:
        return max(0, self._lifetime_cap - self._lifetime_launched)

    @property
    def lifetime_exhausted(self) -> bool:
        return self._lifetime_launched >= self._lifetime_cap

    async def run(
        self,
        coro: Coroutine[Any, Any, T],
        pool: AgentPool,
        label: str,
        timeout: Optional[float] = None,
    ) -> Optional[T]:
        """
        Acquire a concurrency slot and run coro as a tracked task.
        Returns None if lifetime cap is exhausted.
        """
        if self.lifetime_exhausted:
            return None

        self._lifetime_launched += 1

        # Queue here if simultaneous cap is full
        async with self._semaphore:
            task = asyncio.create_task(coro)
            handle = pool.register(label, task)
            return await handle.wait(timeout=timeout)

The key is the async with self._semaphore placement. The semaphore is acquired inside the run() coroutine, which itself is awaited by the caller. When all slots are full, callers pile up waiting for run() to return — they are effectively queued. The queue is FIFO in the order asyncio's event loop wakes waiting coroutines, which is deterministic within a single run.

The lifetime cap check happens before the semaphore acquisition. Once the 1000th agent fires, every subsequent call returns None immediately without entering the semaphore. This prevents a pathological script from queuing thousands of calls that will never run.

28.3 pipeline() Implementation: Streaming Items Through Stages Without Synchronization

The defining property of pipeline() is the absence of a barrier between stages. Item A advances to stage 2 the moment stage 1 completes, regardless of whether items B and C have finished stage 1. This is not an optimization — it is the semantic contract that determines wall-clock performance.

Each stage is a callable that takes (previous_result, original_item, index) and returns an awaitable. If a stage raises, the item becomes None and all subsequent stages are skipped for that item.

from collections.abc import Awaitable


StageFunc = Callable[[Any, Any, int], Awaitable[Any]]


async def pipeline(
    items: list[Any],
    *stages: StageFunc,
    guard: ConcurrencyGuard,
    pool: AgentPool,
    label_prefix: str = "pipeline",
) -> list[Optional[Any]]:
    """
    Process items through stages without inter-stage barriers.

    Item A enters stage 2 as soon as its stage 1 completes.
    Item B does not wait for item A to finish stage 2 before starting.

    A stage that raises → item becomes None, remaining stages skipped.
    Returns array of same length as items; None in failed/skipped positions.
    """
    if not stages:
        return list(items)

    results: list[Optional[Any]] = [None] * len(items)

    async def process_item(original: Any, idx: int) -> None:
        current: Any = original
        for stage_num, stage in enumerate(stages):
            if current is None:
                # Item was dropped by a previous stage — skip remaining
                break
            label = f"{label_prefix}:s{stage_num}:i{idx}"
            try:
                current = await guard.run(
                    _call_stage(stage, current, original, idx),
                    pool=pool,
                    label=label,
                )
            except Exception:
                current = None
                break
        results[idx] = current

    # Launch all items concurrently — they race through stages independently
    await asyncio.gather(*[process_item(item, i) for i, item in enumerate(items)])
    return results


async def _call_stage(
    stage: StageFunc,
    prev_result: Any,
    original_item: Any,
    index: int,
) -> Any:
    """Invoke a stage function, normalizing sync and async callables."""
    result = stage(prev_result, original_item, index)
    if asyncio.iscoroutine(result) or asyncio.isfuture(result):
        return await result
    return result

The outer asyncio.gather() launches a coroutine for every item simultaneously. Each process_item() coroutine then walks through the stages sequentially — but across items this sequential walking happens in parallel. The semaphore inside guard.run() ensures no more than simultaneous_cap agents are executing at any moment.

Notice that the stage loop is sequential per item: process_item awaits each stage before calling the next. This is correct. The per-item ordering is strict — stage 3 of item A cannot start before stage 2 of item A finishes. The inter-item ordering is unconstrained — stage 2 of item A can run while stage 1 of item B is still running.

The timing model follows directly:

gantt
    title pipeline() — 4 items, 3 stages (no barrier)
    dateFormat  ss
    axisFormat  %Ss

    section Item 0
    stage 0 :a0, 0, 3s
    stage 1 :a1, after a0, 4s
    stage 2 :a2, after a1, 2s

    section Item 1
    stage 0 :b0, 1s, 3s
    stage 1 :b1, after b0, 4s
    stage 2 :b2, after b1, 2s

    section Item 2
    stage 0 :c0, 2s, 3s
    stage 1 :c1, after c0, 4s
    stage 2 :c2, after c1, 2s

    section Item 3
    stage 0 :d0, 3s, 3s
    stage 1 :d1, after d0, 4s
    stage 2 :d2, after d1, 2s

Wall-clock time is 12 seconds — the chain length of any single item. With a barrier after each stage it would be 18 seconds (longest stage across all items at each level: 6 + 8 + 4 = 18). No barrier is the correct choice when there is no data dependency between items at a given stage.

28.4 parallel() Implementation: Barrier Semantics — Await All, None on Error, Filter with Boolean

parallel() is a barrier. It takes an array of thunks (zero-argument async functions), launches them all, waits for every one to settle, and returns results in the same order as the input. A thunk that raises resolves to None in the output. The function itself never raises.

ThunkFunc = Callable[[], Awaitable[Any]]


async def parallel(
    thunks: list[ThunkFunc],
    guard: ConcurrencyGuard,
    pool: AgentPool,
    label_prefix: str = "parallel",
) -> list[Optional[Any]]:
    """
    Execute thunks concurrently and await ALL before returning (barrier).

    A throwing thunk → None in output array.
    parallel() itself never raises.
    Use results.filter(Boolean) — i.e., [r for r in results if r] in Python.
    """
    if not thunks:
        return []

    async def run_thunk(thunk: ThunkFunc, idx: int) -> Optional[Any]:
        label = f"{label_prefix}:{idx}"
        try:
            return await guard.run(thunk(), pool=pool, label=label)
        except Exception:
            return None

    # asyncio.gather with return_exceptions=True is NOT used here.
    # Each run_thunk already catches exceptions and returns None.
    # gather itself will not raise.
    return list(await asyncio.gather(*[run_thunk(t, i) for i, t in enumerate(thunks)]))

The difference from pipeline() is architectural. pipeline() advances items through stages; parallel() advances all thunks to completion simultaneously, then returns. The caller can only proceed after the last thunk finishes.

The return_exceptions=False behavior of asyncio.gather is correct here precisely because run_thunk already converts all exceptions to None. There is no path where the outer gather can raise.

The standard usage pattern is:

results = await parallel(
    [
        lambda: agent("Audit for SQL injection"),
        lambda: agent("Audit for path traversal"),
        lambda: agent("Audit for hardcoded secrets"),
    ],
    guard=guard,
    pool=pool,
)
confirmed = [r for r in results if r]

The [r for r in results if r] filter is the Python equivalent of results.filter(Boolean). Always apply it before iterating on the output.

Why parallel() must never reject

This is the most important design constraint to get right in implementation. Promise.all() in JavaScript rejects on the first failure and leaves remaining promises in flight. Python's asyncio.gather() with return_exceptions=False raises on the first exception and cancels remaining tasks. Both behaviors are wrong for an orchestration engine.

An orchestration barrier must:

  1. Allow all tasks to complete
  2. Return results in positional order
  3. Represent failures as None, not exceptions

If one of five parallel security audits crashes due to a malformed schema, the other four should still produce results. The caller decides how to handle a partial result set — the orchestrator does not decide for them by aborting the whole batch.

28.5 Structured Output: Schema Option → StructuredOutput Tool Injection → Validation → Retry on Mismatch

When a caller passes schema to agent(), the engine must guarantee the return value is a valid Python dict matching the JSON Schema, or None. The mechanism has three steps:

  1. Inject a StructuredOutput pseudo-tool into the agent's tool list
  2. Instruct the agent to call this tool exactly once as its final action
  3. Validate the tool call arguments against the schema; retry if invalid
import json
import jsonschema
from typing import Optional


MAX_SCHEMA_RETRIES = 2


async def call_agent_with_schema(
    prompt: str,
    schema: dict[str, Any],
    api_client: Any,
    label: str,
) -> Optional[dict[str, Any]]:
    """
    Run an agent call that must return a validated JSON object.

    Injects a StructuredOutput tool. If the model's response fails
    schema validation, sends the error back and retries once.
    Returns the validated dict or None.
    """
    structured_output_tool = {
        "name": "StructuredOutput",
        "description": (
            "Call this tool exactly once as your final action. "
            "Provide the structured data matching the required schema."
        ),
        "input_schema": schema,
    }

    messages: list[dict[str, Any]] = [{"role": "user", "content": prompt}]

    for attempt in range(MAX_SCHEMA_RETRIES + 1):
        response = await api_client.messages.create(
            model="claude-sonnet-4-6",
            max_tokens=4096,
            tools=[structured_output_tool],
            tool_choice={"type": "any"},
            messages=messages,
        )

        # Extract the StructuredOutput tool call from the response
        tool_call = _extract_tool_call(response, "StructuredOutput")
        if tool_call is None:
            # Model did not call the tool — retry with a corrective message
            if attempt < MAX_SCHEMA_RETRIES:
                messages = _append_correction(
                    messages,
                    response,
                    "You must call the StructuredOutput tool with your final answer.",
                )
            continue

        # Validate arguments against schema
        raw_data = tool_call.get("input", {})
        error = _validate_schema(raw_data, schema)
        if error is None:
            return raw_data  # Valid

        if attempt < MAX_SCHEMA_RETRIES:
            messages = _append_correction(
                messages,
                response,
                f"Schema validation failed: {error}. Please call StructuredOutput again with corrected data.",
            )

    return None  # Exhausted retries


def _extract_tool_call(
    response: Any,
    tool_name: str,
) -> Optional[dict[str, Any]]:
    """Return the first matching tool call from a response, or None."""
    for block in response.content:
        if getattr(block, "type", None) == "tool_use":
            if block.name == tool_name:
                return {"input": block.input}
    return None


def _validate_schema(
    data: Any,
    schema: dict[str, Any],
) -> Optional[str]:
    """Return a validation error string, or None if valid."""
    try:
        jsonschema.validate(instance=data, schema=schema)
        return None
    except jsonschema.ValidationError as exc:
        return exc.message


def _append_correction(
    messages: list[dict[str, Any]],
    response: Any,
    correction: str,
) -> list[dict[str, Any]]:
    """Append the model's response and a correction user turn."""
    # Build assistant turn from response
    assistant_content = [
        block for block in response.content
    ]
    return [
        *messages,
        {"role": "assistant", "content": assistant_content},
        {"role": "user", "content": correction},
    ]

The retry loop is critical: the model sees its own failed response and the validation error, giving it a second attempt with full context about what went wrong. In practice the model self-corrects on the first retry in over 95% of cases. Two retries are sufficient; a third retry almost never adds value and wastes tokens.

The tool_choice: {"type": "any"} forces the model to call a tool on every turn. Without this, a model that cannot satisfy the schema might emit a freeform apology instead of attempting a correction. With it, the model is forced to make a structured response on every turn of the retry loop.

28.6 Progress Reporting: Phase Grouping, Narrator Lines, Real-Time UI Updates

Progress in a multi-agent workflow has two streams: structured events (phase transitions, agent start/complete) and narrator lines (human-readable milestones). Both need to be surfaced in real time — not buffered until the workflow finishes.

The implementation uses an asyncio.Queue as the event bus. The workflow engine posts events; the UI renderer consumes them in a separate coroutine.

from dataclasses import dataclass
from enum import Enum, auto


class EventType(Enum):
    PHASE_START = auto()
    PHASE_END = auto()
    AGENT_START = auto()
    AGENT_COMPLETE = auto()
    AGENT_FAILED = auto()
    LOG = auto()
    BUDGET_UPDATE = auto()


@dataclass
class ProgressEvent:
    type: EventType
    payload: dict[str, Any]
    timestamp: float = field(default_factory=time.monotonic)


class ProgressReporter:
    """
    Thread-safe progress event bus for workflow execution.

    Workflow engine posts events via emit().
    UI renderer consumes events via the async iterator.
    """

    def __init__(self) -> None:
        self._queue: asyncio.Queue[Optional[ProgressEvent]] = asyncio.Queue()
        self._current_phase: Optional[str] = None
        self._phase_counts: dict[str, int] = {}

    def phase(self, title: str) -> None:
        """Begin a named phase. All subsequent agents are grouped under it."""
        self._current_phase = title
        self._phase_counts[title] = 0
        self._queue.put_nowait(ProgressEvent(
            type=EventType.PHASE_START,
            payload={"title": title},
        ))

    def log(self, message: str) -> None:
        """Emit a narrator line visible to the user."""
        self._queue.put_nowait(ProgressEvent(
            type=EventType.LOG,
            payload={"message": message, "phase": self._current_phase},
        ))

    def agent_start(self, label: str) -> None:
        phase = self._current_phase or "default"
        self._phase_counts[phase] = self._phase_counts.get(phase, 0) + 1
        self._queue.put_nowait(ProgressEvent(
            type=EventType.AGENT_START,
            payload={"label": label, "phase": phase},
        ))

    def agent_complete(self, label: str, duration_ms: float) -> None:
        self._queue.put_nowait(ProgressEvent(
            type=EventType.AGENT_COMPLETE,
            payload={
                "label": label,
                "phase": self._current_phase or "default",
                "duration_ms": duration_ms,
            },
        ))

    def agent_failed(self, label: str, reason: str) -> None:
        self._queue.put_nowait(ProgressEvent(
            type=EventType.AGENT_FAILED,
            payload={"label": label, "reason": reason},
        ))

    def close(self) -> None:
        """Signal that no more events will be posted."""
        self._queue.put_nowait(None)

    async def __aiter__(self):
        while True:
            event = await self._queue.get()
            if event is None:
                break
            yield event

A simple terminal renderer:

async def render_progress(reporter: ProgressReporter) -> None:
    """Consume progress events and print to terminal."""
    phase_agent_count: dict[str, int] = {}

    async for event in reporter:
        match event.type:
            case EventType.PHASE_START:
                title = event.payload["title"]
                print(f"\n[{title}]", flush=True)

            case EventType.AGENT_START:
                label = event.payload["label"]
                phase = event.payload["phase"]
                n = phase_agent_count.get(phase, 0) + 1
                phase_agent_count[phase] = n
                print(f"  ({n}) {label} ...", end="", flush=True)

            case EventType.AGENT_COMPLETE:
                ms = event.payload["duration_ms"]
                print(f" done ({ms:.0f}ms)", flush=True)

            case EventType.AGENT_FAILED:
                reason = event.payload.get("reason", "error")
                print(f" FAILED: {reason}", flush=True)

            case EventType.LOG:
                msg = event.payload["message"]
                phase = event.payload.get("phase")
                prefix = f"[{phase}] " if phase else ""
                print(f"  {prefix}{msg}", flush=True)

The renderer runs as a separate asyncio.Task in parallel with the workflow. The workflow never blocks on rendering, and rendering never blocks on the workflow. The queue decouples them.

28.7 Resume/Caching: Journal of (prompt, opts) → Result Pairs, Replay Unchanged Prefix

The journal system turns expensive re-runs into cheap replays. Every agent() call is logged with a stable cache key. On resume with the same run_id, matching entries return their cached result immediately. The first call whose key differs from the journal entry re-runs from that point forward.

The cache key is a hash of the call's observable identity: prompt text, schema, label, model. It deliberately excludes timestamps, random values, and wall-clock state — all of which would cause every call to be a cache miss.

import hashlib
import json
import pathlib


@dataclass
class JournalEntry:
    cache_key: str
    label: str
    result: Any
    token_cost: int
    recorded_at: float


class WorkflowJournal:
    """
    Content-addressable journal for agent call results.

    On first run: records every agent call result.
    On resume with same run_id: replays journal until first mismatch,
    then re-runs from that point forward.
    """

    def __init__(self, run_id: str, journal_dir: pathlib.Path) -> None:
        self._run_id = run_id
        self._path = journal_dir / f"{run_id}.jsonl"
        self._entries: list[JournalEntry] = []
        self._replay_index: int = 0
        self._replay_mode: bool = False
        self._dirty: bool = False

    @classmethod
    def create_new(cls, journal_dir: pathlib.Path) -> "WorkflowJournal":
        """Start a fresh journal with a new run_id."""
        import uuid
        run_id = f"wf_{uuid.uuid4().hex[:8]}"
        journal_dir.mkdir(parents=True, exist_ok=True)
        journal = cls(run_id=run_id, journal_dir=journal_dir)
        return journal

    @classmethod
    def resume(cls, run_id: str, journal_dir: pathlib.Path) -> "WorkflowJournal":
        """Load an existing journal for replay."""
        journal = cls(run_id=run_id, journal_dir=journal_dir)
        if journal._path.exists():
            journal._load()
            journal._replay_mode = True
        return journal

    def _load(self) -> None:
        with self._path.open() as f:
            for line in f:
                line = line.strip()
                if not line:
                    continue
                data = json.loads(line)
                self._entries.append(JournalEntry(**data))

    def make_key(self, prompt: str, opts: dict[str, Any]) -> str:
        """
        Derive a stable cache key from call identity.

        Deliberately excludes: timestamps, random values, wall-clock state.
        These must not appear in prompts or opts if resume is to work.
        """
        canonical = json.dumps(
            {"prompt": prompt, "opts": {k: v for k, v in sorted(opts.items())}},
            sort_keys=True,
            default=str,
        )
        return hashlib.sha256(canonical.encode()).hexdigest()[:16]

    def lookup(self, cache_key: str) -> tuple[bool, Any]:
        """
        Check if this call hits the replay buffer.

        Returns (True, cached_result) on hit.
        Returns (False, None) on miss — caller must run the agent.
        A miss disables replay mode for all subsequent calls.
        """
        if not self._replay_mode:
            return False, None

        if self._replay_index >= len(self._entries):
            self._replay_mode = False
            return False, None

        entry = self._entries[self._replay_index]
        if entry.cache_key == cache_key:
            self._replay_index += 1
            return True, entry.result
        else:
            # First mismatch — disable replay from here forward
            self._replay_mode = False
            return False, None

    def record(
        self,
        cache_key: str,
        label: str,
        result: Any,
        token_cost: int = 0,
    ) -> None:
        """Append a new entry to the journal."""
        entry = JournalEntry(
            cache_key=cache_key,
            label=label,
            result=result,
            token_cost=token_cost,
            recorded_at=time.time(),
        )
        self._entries.append(entry)
        self._dirty = True
        with self._path.open("a") as f:
            f.write(json.dumps({
                "cache_key": entry.cache_key,
                "label": entry.label,
                "result": entry.result,
                "token_cost": entry.token_cost,
                "recorded_at": entry.recorded_at,
            }) + "\n")

    @property
    def run_id(self) -> str:
        return self._run_id

    @property
    def cached_token_savings(self) -> int:
        """Tokens saved by replaying cached calls in this resume."""
        return sum(
            e.token_cost
            for e in self._entries[:self._replay_index]
        )

The "longest unchanged prefix" behavior falls out of the lookup() implementation. As long as calls arrive in the same order with the same keys, they replay. The first mismatch — caused by a prompt edit, a new stage insertion, or a schema change — terminates replay mode. All calls after the mismatch run fresh and are appended to the journal, extending it for the next resume.

This is why determinism is required. Any time.time() or random.random() call inside a prompt string will generate a different cache key on every run. The journal will always miss. A workflow that has even one non-deterministic interpolation in a prompt cannot benefit from resume.

# WRONG — cache key will never match on resume
prompt = f"Analyze {file_path} at timestamp {time.time()}"

# CORRECT — cache key is stable across runs
prompt = f"Analyze {file_path}"

28.8 Lab: Build a Workflow Engine with pipeline/parallel/phase/budget Primitives

This lab integrates every component from this chapter into a working Python workflow engine. The engine exposes the same primitives as Claude Code's Workflow runtime: agent(), pipeline(), parallel(), phase(), log(), and budget.

Engine Core

from __future__ import annotations

import asyncio
import os
import pathlib
import time
from dataclasses import dataclass, field
from typing import Any, Callable, Optional

import anthropic


@dataclass
class BudgetTracker:
    total: Optional[int]  # None if no budget directive
    _spent: int = field(default=0, init=False)

    def add(self, tokens: int) -> None:
        self._spent += tokens

    def spent(self) -> int:
        return self._spent

    def remaining(self) -> float:
        if self.total is None:
            return float("inf")
        return max(0, self.total - self._spent)

    @property
    def exhausted(self) -> bool:
        if self.total is None:
            return False
        return self._spent >= self.total


class WorkflowEngine:
    """
    Multi-agent workflow engine with pipeline, parallel, phase, budget,
    and journal-based resume.

    Usage:
        async with WorkflowEngine(budget_tokens=500_000) as engine:
            engine.phase("Discovery")
            files = await engine.agent("List all Python files in src/")
            engine.phase("Analysis")
            results = await engine.pipeline(
                files,
                lambda f, orig, i: engine.agent(f"Analyze {f}", label=f"analyze:{i}"),
            )
    """

    def __init__(
        self,
        budget_tokens: Optional[int] = None,
        run_id: Optional[str] = None,
        journal_dir: pathlib.Path = pathlib.Path.home() / ".harness" / "journals",
        simultaneous_cap: Optional[int] = None,
    ) -> None:
        self._budget = BudgetTracker(total=budget_tokens)
        self._guard = ConcurrencyGuard(
            simultaneous_cap=simultaneous_cap or _DEFAULT_CAP
        )
        self._pool = AgentPool()
        self._reporter = ProgressReporter()
        self._client = anthropic.AsyncAnthropic()
        self._current_phase: Optional[str] = None

        # Journal setup
        if run_id is not None:
            self._journal = WorkflowJournal.resume(run_id, journal_dir)
        else:
            self._journal = WorkflowJournal.create_new(journal_dir)

    async def __aenter__(self) -> "WorkflowEngine":
        # Start the progress renderer as a background task
        self._renderer_task = asyncio.create_task(
            render_progress(self._reporter)
        )
        return self

    async def __aexit__(self, *_: Any) -> None:
        self._reporter.close()
        await self._renderer_task
        await self._pool.cancel_all()

    @property
    def run_id(self) -> str:
        return self._journal.run_id

    @property
    def budget(self) -> BudgetTracker:
        return self._budget

    def phase(self, title: str) -> None:
        """Set current phase for progress grouping."""
        self._current_phase = title
        self._reporter.phase(title)

    def log(self, message: str) -> None:
        """Emit a narrator line to the progress UI."""
        self._reporter.log(message)

    async def agent(
        self,
        prompt: str,
        *,
        label: Optional[str] = None,
        schema: Optional[dict[str, Any]] = None,
        model: str = "claude-sonnet-4-6",
        timeout: Optional[float] = None,
    ) -> Optional[Any]:
        """
        Spawn a subagent. Returns validated dict if schema provided,
        string otherwise, or None on failure/budget exhaustion.
        """
        if self._budget.exhausted:
            self.log(f"Budget exhausted — skipping agent '{label or prompt[:40]}'")
            return None

        if self._guard.lifetime_exhausted:
            self.log("Lifetime agent cap (1000) reached — further calls return None")
            return None

        effective_label = label or f"agent:{self._current_phase or 'default'}"
        opts: dict[str, Any] = {"schema": schema, "model": model}
        cache_key = self._journal.make_key(prompt, opts)

        # Check journal for cached result
        hit, cached = self._journal.lookup(cache_key)
        if hit:
            self.log(f"[cache hit] {effective_label}")
            return cached

        # Run the agent
        self._reporter.agent_start(effective_label)
        started = time.monotonic()

        result = await self._guard.run(
            self._run_agent(prompt, schema=schema, model=model),
            pool=self._pool,
            label=effective_label,
            timeout=timeout,
        )

        duration_ms = (time.monotonic() - started) * 1000
        if result is None:
            self._reporter.agent_failed(effective_label, "null result")
        else:
            self._reporter.agent_complete(effective_label, duration_ms)

        # Record in journal
        self._journal.record(cache_key, effective_label, result)
        return result

    async def _run_agent(
        self,
        prompt: str,
        schema: Optional[dict[str, Any]],
        model: str,
    ) -> Optional[Any]:
        """Internal: call the API, optionally with structured output."""
        if schema is not None:
            return await call_agent_with_schema(
                prompt=prompt,
                schema=schema,
                api_client=self._client,
                label="agent",
            )

        # Plain text response
        response = await self._client.messages.create(
            model=model,
            max_tokens=4096,
            messages=[{"role": "user", "content": prompt}],
        )
        # Track token usage
        usage = getattr(response, "usage", None)
        if usage:
            self._budget.add(getattr(usage, "output_tokens", 0))

        # Extract text content
        for block in response.content:
            if getattr(block, "type", None) == "text":
                return block.text
        return None

    async def pipeline(
        self,
        items: list[Any],
        *stages: StageFunc,
    ) -> list[Optional[Any]]:
        """
        Process items through stages without inter-stage barriers.
        Delegates to the module-level pipeline() with this engine's guard/pool.
        """
        # Wrap raw agent calls in the engine's agent() method
        return await pipeline(
            items,
            *stages,
            guard=self._guard,
            pool=self._pool,
            label_prefix=f"pipeline:{self._current_phase or 'default'}",
        )

    async def parallel(
        self,
        thunks: list[ThunkFunc],
    ) -> list[Optional[Any]]:
        """
        Execute thunks concurrently with barrier semantics.
        """
        return await parallel(
            thunks,
            guard=self._guard,
            pool=self._pool,
            label_prefix=f"parallel:{self._current_phase or 'default'}",
        )

Example Workflow: Three-Phase Code Review

import asyncio


FINDING_SCHEMA = {
    "type": "object",
    "required": ["findings", "clean"],
    "properties": {
        "findings": {
            "type": "array",
            "items": {
                "type": "object",
                "required": ["file", "severity", "summary"],
                "properties": {
                    "file": {"type": "string"},
                    "severity": {
                        "type": "string",
                        "enum": ["low", "medium", "high", "critical"],
                    },
                    "summary": {"type": "string"},
                },
                "additionalProperties": False,
            },
        },
        "clean": {"type": "boolean"},
    },
    "additionalProperties": False,
}

REPORT_SCHEMA = {
    "type": "object",
    "required": ["executive_summary", "critical_count", "high_count"],
    "properties": {
        "executive_summary": {"type": "string"},
        "critical_count": {"type": "integer"},
        "high_count": {"type": "integer"},
        "recommendations": {"type": "array", "items": {"type": "string"}},
    },
    "additionalProperties": False,
}


async def run_code_review(
    files: list[str],
    budget_tokens: int = 300_000,
    resume_run_id: Optional[str] = None,
) -> Optional[dict[str, Any]]:
    """
    Three-phase workflow: scan → verify → synthesize.
    Pass resume_run_id to replay unchanged prefix from a prior run.
    """
    async with WorkflowEngine(
        budget_tokens=budget_tokens,
        run_id=resume_run_id,
    ) as engine:
        engine.log(f"Starting review of {len(files)} files")
        engine.log(
            f"Budget: {budget_tokens:,} tokens | "
            f"Run ID: {engine.run_id}"
        )

        # Phase 1: Scan — pipeline with no barrier
        engine.phase("Scan")
        engine.log(f"Scanning {len(files)} files...")

        scan_results = await engine.pipeline(
            files,
            lambda f, _orig, i: engine.agent(
                f"Review this file for security and correctness issues: {f}\n"
                "Use the Read tool to examine the file. "
                "Report only real issues — set clean: true if the file has none.",
                label=f"scan:{pathlib.Path(f).name}",
                schema=FINDING_SCHEMA,
            ),
        )

        all_findings = [
            finding
            for result in scan_results
            if result and not result.get("clean")
            for finding in result.get("findings", [])
        ]
        high_critical = [
            f for f in all_findings
            if f["severity"] in ("high", "critical")
        ]

        engine.log(
            f"Scan complete — {len(all_findings)} findings, "
            f"{len(high_critical)} high/critical"
        )

        # Phase 2: Verify high/critical findings — parallel with barrier
        engine.phase("Verify")
        confirmed: list[dict[str, Any]] = []

        if high_critical and engine.budget.remaining() > len(high_critical) * 3000:
            engine.log(f"Verifying {len(high_critical)} high/critical findings")

            verifications = await engine.parallel([
                (lambda f: lambda: engine.agent(
                    f"Adversarially verify this finding. Default to confirmed=False "
                    f"if uncertain.\n\nFinding: {f['summary']}\nFile: {f['file']}",
                    label=f"verify:{f['file']}",
                    schema={
                        "type": "object",
                        "required": ["confirmed", "reason"],
                        "properties": {
                            "confirmed": {"type": "boolean"},
                            "reason": {"type": "string"},
                        },
                        "additionalProperties": False,
                    },
                ))(finding)
                for finding in high_critical
            ])

            confirmed = [
                high_critical[i]
                for i, v in enumerate(verifications)
                if v and v.get("confirmed")
            ]
            dropped = len(high_critical) - len(confirmed)
            engine.log(
                f"Verification complete — {len(confirmed)} confirmed, "
                f"{dropped} false positives eliminated"
            )
        else:
            engine.log("Skipping verification — insufficient budget or no high/critical findings")
            confirmed = high_critical

        # Phase 3: Synthesize — single agent call
        engine.phase("Synthesize")
        all_confirmed = confirmed + [
            f for f in all_findings if f["severity"] in ("low", "medium")
        ]

        if not all_confirmed:
            engine.log("No findings to synthesize — codebase appears clean")
            return {"executive_summary": "No issues found.", "critical_count": 0, "high_count": 0}

        findings_text = "\n".join(
            f"- [{f['severity'].upper()}] {f['file']}: {f['summary']}"
            for f in all_confirmed
        )

        report = await engine.agent(
            f"Generate an engineering-team security review report.\n\n"
            f"Confirmed findings ({len(all_confirmed)}):\n{findings_text}\n\n"
            "Provide an executive summary, counts by severity, "
            "and prioritized recommendations.",
            label="synthesize",
            schema=REPORT_SCHEMA,
            model="claude-opus-4-8",
        )

        engine.log(
            f"Complete — "
            f"{report['critical_count'] if report else 0} critical, "
            f"{report['high_count'] if report else 0} high"
        )
        engine.log(f"Tokens used: {engine.budget.spent():,}")
        return report


# Entry point
if __name__ == "__main__":
    import sys

    target_files = sys.argv[1:] or ["src/auth.py", "src/api.py", "src/db.py"]
    resume_id = os.environ.get("RESUME_RUN_ID")

    report = asyncio.run(
        run_code_review(
            files=target_files,
            budget_tokens=300_000,
            resume_run_id=resume_id,
        )
    )

    if report:
        print(f"\nExecutive Summary: {report['executive_summary']}")
        print(f"Critical: {report['critical_count']}, High: {report['high_count']}")

async def test_pipeline_no_barrier():
    """Items in later stages should not wait for earlier items in earlier stages."""
    guard = ConcurrencyGuard(simultaneous_cap=10)
    pool = AgentPool()
    order: list[str] = []

    async def stage1(item: str, _orig: str, _i: int) -> str:

        order.append(f"s1:{item}")

        stage2,
        guard=guard,
        pool=pool,

    assert results == ["slow", "fast"]
    # "fast" should reach stage2 before "slow" does
    assert order.index("s2:fast") < order.index("s2:slow")


@pytest.mark.asyncio
async def test_parallel_barrier_awaits_all():
    """parallel() must await all thunks even if one is slow."""
    guard = ConcurrencyGuard(simultaneous_cap=10)
    pool = AgentPool()

            await asyncio.sleep(delay)
            completed.append(n)

Summary

The orchestration engine is the piece that separates a single-agent chat loop from a programmable multi-agent system. The components in this chapter are individually simple. Their power comes from composition.

The semaphore is a queue, not a gate. Excess agent launches wait — they do not fail. This means pipeline() and parallel() with hundreds of items work correctly even on machines with 4 CPU cores; they are slower, but they complete.

pipeline() has no barrier. Items race through stages independently. The wall-clock time of a pipeline is the length of the slowest single-item chain, not the sum of the slowest stage per level. Every unnecessary barrier doubles or triples latency on real workloads.

parallel() is a barrier. Every thunk completes before the caller proceeds. Throws become None. The function never raises. Use [r for r in results if r] on every output before iterating.

Structured output is a retry loop. Inject the StructuredOutput tool, validate the arguments against the JSON Schema, send the error back if invalid, retry once. Two retries are sufficient in practice. Schema design discipline — flat objects, enums for categoricals, additionalProperties: False — determines how often you need that second attempt.

The journal makes resume free. Cache keys are stable hashes of prompt plus opts. Determinism is required: no time.time(), no random.random(), no wall-clock interpolation in prompts. A workflow that changed only its synthesis prompt replays 200 scan agents from cache and re-runs only the synthesis.

Progress reporting is a separate concern. The ProgressReporter event bus decouples the workflow engine from the UI renderer. The workflow never blocks on rendering. The renderer never blocks on the workflow.

Chapter 29 builds the extension layer on top of this engine: hook execution, skill loading, and a plugin marketplace. The orchestration engine you built here is the substrate those extension points run on.
