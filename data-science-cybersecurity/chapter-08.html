Chapter 8: Specialized Data: Time, Text, Graphs, and Streams

Investigation Packet: One Identity, Four Laboratories

Identity u-17 generated an unusual midnight burst, an analyst note mentions “consent phishing,” a newly registered application reaches a privileged group through delegated permissions, and events arrive out of order from two collectors. Flattening all evidence into one feature table would erase useful structure. Treating every structure with a specialized model would create unjustified complexity.

The four laboratories below ask separate questions:

  • time series: did a count process depart from its own seasonal baseline?
  • text: which documented incidents resemble the current note, and why?
  • graph: what reachable privilege path exists?
  • stream: what can be known at event time when records are late?

Only after each laboratory produces a validated artifact do we design fusion.

Laboratory A: A Seasonal Count Is Not an IID Column

We observe hourly privileged-action counts for fourteen days. Normal activity has an hour-of-day pattern; the last night contains a burst. A global z-score would call busy daytime hours anomalous and might miss a smaller but extraordinary nighttime count. Estimate a robust seasonal baseline separately for each hour of day using the median and median absolute deviation (MAD).

import numpy as np
rng=np.random.default_rng(8)
hours=np.arange(14*24)
hour_of_day=hours%24
seasonal=np.where((hour_of_day>=8)&(hour_of_day<18),6,1)
counts=rng.poisson(seasonal).astype(float)
counts[-5]=12

score=np.zeros_like(counts)
for h in range(24):
    idx=np.where(hour_of_day==h)[0]
    history=counts[idx[:-1]]
    median=np.median(history)
    mad=np.median(np.abs(history-median))
    scale=max(1.0,1.4826*mad)
    score[idx[-1]]=(counts[idx[-1]]-median)/scale

top=np.argsort(score)[-3:][::-1]
for i in top: print(int(i),int(hour_of_day[i]),int(counts[i]),round(float(score[i]),2))

Exact expected output:

331 19 12 12.0
320 8 13 6.07
323 11 12 2.36

The score is a screening statistic, not a probability of attack. With only thirteen historical observations per seasonal cell, uncertainty is substantial. A production baseline should define minimum history, holiday handling, daylight-saving behavior, and a fallback for unseen seasonal cells.

Trend, autocorrelation, and regime change

A moving average smooths noise but lags a step change. Exponential smoothing weights recent observations more heavily. Forecast residuals must be checked for autocorrelation; correlated residuals invalidate the intuition that repeated threshold crossings are independent evidence. For count data, Poisson or negative-binomial models may be more appropriate than Gaussian errors, especially when variance grows with mean.

Change-point detection asks whether the generating regime shifted, not whether one point is extreme. A cumulative-sum detector can identify sustained mean movement, but its reference mean and threshold must be chosen on pre-change data. Evaluate detection delay and false alarms per unit time on replayed sequences. Never randomly shuffle time-series observations for validation.

Event histories differ from aggregate series. “MFA succeeded, token issued, consent granted, mailbox read” is an ordered sequence whose gaps matter. Markov, survival, recurrent, or transformer approaches may model it, but simple elapsed-time and n-gram baselines should come first. Sequence windows must end at the decision timestamp to avoid future leakage.

Laboratory B: Retrieve Analyst Notes Without Inventing Meaning

The current note should be compared with a controlled incident corpus. TF-IDF provides a transparent baseline: terms frequent in one document but common across all documents receive less weight. Character or word n-grams can capture phrases; preprocessing must preserve security tokens such as OAuth, C2, hashes, and command fragments.

import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

corpus=[
 "user approved oauth consent phishing application mailbox access",
 "powershell encoded command endpoint malware quarantine",
 "impossible travel login new device token theft",
 "oauth application delegated mail read privilege escalation"]
query="analyst suspects consent phishing and delegated mailbox permission"
vectorizer=TfidfVectorizer(ngram_range=(1,2),lowercase=True)
matrix=vectorizer.fit_transform(corpus+[query])
similarity=cosine_similarity(matrix[-1],matrix[:-1]).ravel()
for i in np.argsort(similarity)[::-1]: print(i,round(float(similarity[i]),3))

Exact expected output:

0 0.199
3 0.052
2 0.0
1 0.0

Retrieval says notes 0 and 3 share weighted language with the query. It does not say they have the same root cause. Inspect matched terms, corpus date, author conventions, and whether templated ticket text dominates similarity.

Embeddings, classifiers, topics, and LLM assistance

Embeddings help when semantically similar notes use different vocabulary, but their model version and truncation policy become data lineage. Benchmark them against lexical retrieval using labeled relevance judgments, recall at candidate depth, and subgroup slices such as language or product. Do not evaluate only on notes used to tune prompts.

A text classifier needs a point-in-time label and must exclude resolution text written after investigation. Topic models summarize co-occurrence, not stable threat categories; assess topic coherence and usefulness with analysts rather than assigning authoritative names from top words.

An LLM can extract entities or draft a synopsis, but require a schema, source-span citations, abstention behavior, and a held-out evaluation set. Treat prompt, model identifier, decoding settings, retrieval corpus, and safety policy as versioned dependencies. Measure unsupported-claim rate and omission of critical entities. Never let generated prose overwrite the original note.

Laboratory C: Traverse the Privilege Graph

Represent identities, applications, groups, and resources as typed nodes. Edges carry relations and validity intervals: CONSENTED_TO, HAS_PERMISSION, MEMBER_OF, or CAN_ADMIN. Direction matters. A high-degree node is not automatically dangerous; a short valid path to a crown-jewel permission is often more actionable.

import networkx as nx
G=nx.DiGraph()
edges=[
 ("user:u17","app:mail-sync","consented"),
 ("app:mail-sync","scope:mail.read","has_scope"),
 ("scope:mail.read","resource:executive-mail","permits"),
 ("user:u17","group:contractors","member"),
 ("group:contractors","resource:wiki","reads")]
for source,target,relation in edges: G.add_edge(source,target,relation=relation)
path=nx.shortest_path(G,"user:u17","resource:executive-mail")
print(" -> ".join(path))
print([G[a][b]["relation"] for a,b in zip(path,path[1:])])
print(sorted(nx.descendants(G,"user:u17")))

Exact expected output:

user:u17 -> app:mail-sync -> scope:mail.read -> resource:executive-mail
['consented', 'has_scope', 'permits']
['app:mail-sync', 'group:contractors', 'resource:executive-mail', 'resource:wiki', 'scope:mail.read']

The path is evidence only if edges were valid at the event time. Store valid_from, valid_to, source system, and observation time. A revoked grant retained as a timeless edge creates phantom exposure. A missing edge can break a real path.

Centrality is not a risk score

Degree counts adjacent edges. Betweenness measures how often a node lies on shortest paths. PageRank-like measures propagate importance under a random-walk assumption. These are structural summaries, not compromise probabilities. In permission graphs, shortest paths may also be semantically invalid if relation types cannot compose. Define allowed path patterns, such as identity → application → scope → resource, and reject nonsensical traversals.

Community detection can reveal dense clusters but is unstable under parameter changes and may rediscover organizational structure. Graph embeddings and graph neural networks can exploit topology, yet temporal leakage is easy: a graph snapshot built after an incident can contain remediation edges or labels. Compare against typed path counts and neighborhood features before adopting a complex model.

Laboratory D: Event Time, Watermarks, and Late Records

Two timestamps are essential. Event time describes when the action occurred; processing time describes when the system received it. A watermark is the system's claim that event time up to a boundary is mostly complete. It is not the latest observed timestamp and not a guarantee that nothing later will arrive.

Consider a ten-minute tumbling window and five minutes of allowed lateness:

from datetime import datetime, timezone, timedelta

events=[("e1","10:02","10:03"),("e2","10:08","10:09"),
        ("e3","10:04","10:17"),("e4","10:16","10:18")]
def minute(text):
    h,m=map(int,text.split(":")); return datetime(2026,8,1,h,m,tzinfo=timezone.utc)

max_event=None; windows={}; emitted=set()
for event_id,event_text,arrival_text in events:
    event_time=minute(event_text); arrival=minute(arrival_text)
    max_event=event_time if max_event is None else max(max_event,event_time)
    watermark=max_event-timedelta(minutes=5)
    start=event_time.replace(minute=(event_time.minute//10)*10,second=0)
    late=start+timedelta(minutes=10)<=watermark
    windows[start]=windows.get(start,0)+1
    print(event_id,"watermark",watermark.strftime("%H:%M"),"late",late,
          "window",start.strftime("%H:%M"),"count",windows[start])

Exact output:

e1 watermark 09:57 late False window 10:00 count 1
e2 watermark 10:03 late False window 10:00 count 2
e3 watermark 10:03 late False window 10:00 count 3
e4 watermark 10:11 late False window 10:10 count 1

This miniature uses max_event - 5 minutes; production systems often derive watermarks per partition and take a conservative minimum so one fast partition cannot close another's window. Arrival timestamp is shown for clarity but processing delay alone does not determine lateness; lateness is relative to the current watermark and window boundary.

What happens after a result is emitted? Three choices are legitimate:

  • discard later records and measure drop rate;
  • update the result and emit a retraction or new version;
  • route late records to a correction stream and recompute downstream state.

The consumer determines which is safe. A dashboard may accept updates. An automatic account suspension cannot quietly retract a decision after harm; it needs conservative thresholds and compensating workflow.

State must be bounded. Evict window state only after the lateness policy, deduplicate by stable event ID within a declared horizon, checkpoint state, and make sinks idempotent. Exactly-once delivery claims do not create exactly-once business effects when an external action is nontransactional. Use idempotency keys and an action ledger.

Incremental mean can be updated with \(m_n=m_{n-1}+(x_n-m_{n-1})/n\); Welford's method adds stable variance. Quantiles and distinct counts need sketches or retained state. Online learning must account for delayed labels: updating a model from immediate analyst actions may encode the current policy rather than eventual truth.

Fusion Design: Join Decisions, Not Raw Modalities

The laboratories yield four artifacts with different clocks and confidence:

  1. a seasonal residual for u-17 at event time;
  2. retrieved note IDs with similarity and matched spans;
  3. typed, time-valid privilege paths;
  4. a windowed event count with watermark, revision, and completeness status.

Early fusion would concatenate everything into one vector. It is tempting but fragile: missing notes become arbitrary zeros, graph snapshots leak future edges, and late stream corrections mutate features after scoring. Prefer late fusion here. Each specialist produces a versioned feature plus provenance and validity interval. A small tabular model or explicit policy combines them only when aligned to the decision timestamp.

For example, queue an investigation when the seasonal residual exceeds 6, a valid path reaches executive mail, and either the note retriever finds a consent-phishing precedent above a validated threshold or the new-application count is elevated. This conjunctive policy is interpretable and testable. A learned meta-model may replace it after enough labeled incidents exist.

The online feature record should carry:

{"identity_id":"u-17","as_of":"2026-08-01T10:20:00Z","seasonal_residual":11.0,"text_match":{"case_id":"case-104","similarity":0.251},"privilege_path":{"target":"resource:executive-mail","hops":3,"graph_snapshot":"g-884"},"stream":{"window":"10:10/10:20","count":4,"watermark":"10:15","revision":1,"complete":false}}

Do not treat complete:false as zero evidence. The policy can wait, degrade to a conservative mode, or score with an explicit missingness indicator. When a late event changes revision 1 to revision 2, store both the original decision context and corrected feature state. Otherwise post-incident review cannot reconstruct what the system knew.

Proving fusion adds value

Compare the fusion design with four ablations and a simple tabular baseline. Use temporal incident-level splits so events from one campaign do not cross folds. Measure precision and recall at review capacity, detection delay, calibration if probabilities are emitted, late-correction frequency, and performance when each modality is missing. Fusion is justified only when improvement is stable and greater than its operational cost.

Text may add no incremental value once the graph path is known; graph freshness may be too poor for real time; a time-series residual may flood on planned maintenance. Ablation is not an academic ritual—it identifies which pipeline can fail without changing the decision.

Fusion also needs a temporal join rule. For every feature, choose the most recent version whose source evidence was observable at or before as_of; never join to the latest row merely because it is convenient. Enforce a maximum age per modality and return stale or unknown when the bound is exceeded. Offline replay must reproduce those availability delays, including graph publication lag and note-index refresh, or it will evaluate an oracle unavailable online.

Privacy boundaries can favor fusion of decisions over raw content. The text service can return a case identifier, similarity, matched spans, and policy-approved entities while the fusion store avoids retaining full notes. The graph service can return a path proof rather than its entire tenant graph. Minimize access while preserving enough provenance for review and correction.

Set separate retention periods for raw events, window state, text evidence, graph snapshots, feature revisions, and action logs. Deleting one layer too early can make an incident unreconstructable; retaining everything indefinitely expands privacy and breach impact. Test deletion and replay procedures together so governance rules do not silently break model evaluation.

Interview Practicum

Real-Time Account Compromise

Prompt with changing facts

“Combine event streams, analyst text, and an identity graph to detect account compromise in real time.” The panel then adds that graph updates lag fifteen minutes, notes may contain personal data, five percent of events arrive more than ten minutes late, and automatic account lockout is forbidden.

Worked Answer

Event-time design response

Clarify the decision: produce a ranked investigation queue, not a lockout. Define event time, maximum tolerable detection delay, review capacity, label maturity, and the graph relations that create meaningful access paths.

Build separate, testable processors. The stream processor computes bounded-window behavioral features using per-partition watermarks, deduplication, versioned corrections, and idempotent output. The graph service answers typed, time-valid reachability against a snapshot ID and exposes snapshot age. The text service performs access-controlled retrieval or schema-bound extraction; it stores source spans, redacts unnecessary personal data, and never makes generated text the sole alert basis.

Fuse late using as_of timestamps and freshness metadata. If the graph is older than fifteen minutes, mark it stale and avoid interpreting “no path” as safety. Score complete and degraded modes separately. Queue records include feature versions, watermark, graph snapshot, retrieved evidence, and revision. Evaluate through temporal campaign splits, ablations, capacity metrics, detection delay, late-data corrections, and missing-modality stress tests.

Because lockout is forbidden, actions are analyst review, step-up recommendation, or evidence collection. Human review is not a vague box: define the evidence shown, service-level objective, disposition vocabulary, and sampled audit of low-ranked events to reduce selective-label bias.

Multimodal architecture traps

“Put everything in a vector database” confuses storage with temporal semantics. “Use a graph neural network” skips typed-path validity and label volume. “Drop late events” hides measured evidence. “Have an LLM read all notes” ignores privacy, provenance, hallucination, and evaluation. “Exactly once” does not make an external response reversible.

Follow-Up Questions and Answers

Late-data follow-ups

A late record changes a previously published feature. Emit revision 2 with an idempotency key, retain revision 1 for audit, recompute the queue if still actionable, and measure correction frequency and decision impact.

The graph says no path but is stale. Return unknown with snapshot age, not false. Use other modalities for ranking and request a refreshed traversal before asserting containment.

How do you show fusion is necessary? Run modality ablations on temporal campaign-level tests and compare queue discoveries, delay, calibration, and degraded-mode behavior against added latency and failure surface.

Spoken fusion recommendation

Thirty seconds: “I would keep time, text, graph, and stream processors independently testable, align their outputs by event-time validity, and fuse versioned evidence late. Watermarks and graph freshness become model inputs, late corrections create new revisions, and the product is a review queue—not an irreversible automated lockout.”

Key Takeaways

  • Preserve the structure that carries meaning: seasonal time, text context, typed reachability, and event-time completeness.
  • Specialized scores are claims about a reference process, not interchangeable probabilities of compromise.
  • Graph edges need types and validity intervals; text outputs need source evidence and versioned models.
  • A watermark states bounded completeness, and late-data policy must specify correction, retraction, or discard behavior.
  • Late fusion with timestamps, snapshot IDs, revisions, and missingness is safer than blindly concatenating modalities.
  • Fusion earns its complexity only through temporal ablation tests and reliable degraded modes.
